# Toimittajakysely: tekoäly ja EU:n tekoälyasetus

> Lähetetään tekoälyä sisältävän järjestelmän tai palvelun toimittajalle. Vastaukset liitetään inventaarioon ja tarvittaessa sopimukseen.

**Toimittaja:**  **Tuote ja versio:**  **Vastaaja ja pvm:**

## A. Tekoälyn käyttö

1. Mitkä tuotteen toiminnot käyttävät tekoälyä? Kuvaa lyhyesti, mitä kukin tekee.
2. Mitä malleja tai kolmansien osapuolten tekoälypalveluja tuote käyttää (toimittaja, malli, käsittelysijainti)?
3. Käytetäänkö asiakkaan tietoja mallien koulutukseen tai parantamiseen? Voiko sen estää?

## B. Rooli ja luokitus

4. Mikä on rooli tekoälyasetuksessa: tarjoaja, maahantuoja, jakelija? Onko EU:n ulkopuolisella tarjoajalla valtuutettu edustaja (22 art.)?
5. Mikä on tuotteen käyttötarkoitus tarjoajan ilmoittamana?
6. Onko tuote arvioitu suuririskiseksi (6 art., liitteet I ja III)? Jos ei, onko vedottu 6 artiklan 3 kohdan poikkeukseen? Toimittakaa arvio.
7. Koskevatko tuotetta 50 artiklan avoimuusvelvoitteet? Miten ne on toteutettu (ilmoitus käyttäjälle, synteettisen sisällön koneluettava merkintä)?

## C. Suuririskiset järjestelmät (jos sovelletaan)

8. Käyttöohjeet (13 art.): toimittakaa tai kertokaa, milloin ne ovat saatavilla.
9. Laadunhallintajärjestelmä (17 art.), tekninen dokumentaatio (11 art.), vaatimustenmukaisuuden arviointi (43 art.) ja EU-vaatimustenmukaisuusvakuutus (47 art.): tila ja aikataulu.
10. Rekisteröinti EU:n tietokantaan (49 art.).
11. Ihmisen suorittaman valvonnan toiminnot (14 art.) ja lokit (12 art.): mitä käyttöönottajalle annetaan, ja kuinka kauan lokeja säilytetään?
12. Tarkkuus, vakaus ja kyberturvallisuus (15 art.): mittarit ja testaus.
13. Vinoumien testaus ja datanhallinta (10 art.).

## D. Muutokset ja vaaratilanteet

14. Miten asiakkaalle ilmoitetaan merkittävistä muutoksista, mallin vaihdoista ja uusista tekoälytoiminnoista?
15. Miten vakavista vaaratilanteista ja tunnistetuista riskeistä ilmoitetaan asiakkaalle?

## E. Yleiskäyttöiset mallit

16. Jos tuote perustuu yleiskäyttöiseen tekoälymalliin, onko mallin tarjoaja sitoutunut yleiskäyttöisten mallien käytännesääntöihin, ja toimittaako se 53 artiklan mukaiset tiedot alavirran tarjoajille?

## F. Sopimus

17. Hyväksyykö toimittaja sopimusehdot, jotka koskevat tekoälyasetuksen noudattamista, tiedonantoa ja yhteistyötä viranomaisten kanssa (25 art. 4 kohta)?

## G. Sopimusehdot ja hankinta

> Hankinta- ja sopimusvaihetta varten. Ehdot ovat suosituksia, jotka organisaatio mukauttaa riskiin. Ne eivät ole lakisääteisiä vaatimuksia, ellei peruste ole merkitty.

| # | Ehto | Toimittajan vastaus | Huomio |
|---|---|---|---|
| 18 | Toimittaja vastaa tekoälyasetuksen ja muun sovellettavan sääntelyn noudattamisesta koko sopimuskauden ajan, myös sääntelyn muuttuessa. | | |
| 19 | Toimittaja ilmoittaa etukäteen uusista tekoälytoiminnoista ja olemassa olevien olennaisista muutoksista (malli, käyttötarkoitus, alikäsittelijä, käsittelysijainti). Asiakas voi jättää uuden toiminnon käyttöön ottamatta tai kytkeä sen pois. | | |
| 20 | Asiakas voi keskeyttää tekoälytoiminnon käytön, jos se aiheuttaa riskin tai on vaatimustenvastainen, ilman sopimusrikkomusta. Suuririskisen järjestelmän käyttöönottajan on keskeytettävä käyttö 26 art. 5 kohdan tilanteissa. | | |
| 21 | Tiedonsaanti- ja auditointioikeus: dokumentaatio, testaus- ja arviointitulokset, todistukset sekä kohtuullinen tarkastusoikeus asiakkaalle tai sen valtuuttamalle tarkastajalle. | | |
| 22 | Asiakkaan tietoja, syötteitä ja tuotoksia ei käytetä mallien koulutukseen tai parantamiseen ilman erillistä sopimusta. Säilytysajat ja poisto sopimuksen päättyessä on sovittu. | | |
| 23 | Suuririskisissä järjestelmissä lokit ovat asiakkaan saatavilla ja säilytettävissä vähintään 26 art. 6 kohdan edellyttämän ajan. | | |
| 24 | Yhteistyö riskeissä, vaaratilanteissa ja viranomaispyynnöissä: nimetty yhteyshenkilö, ilmoitusten määräajat ja tiedot, joita asiakas tarvitsee omien velvoitteidensa täyttämiseen. | | |
| 25 | Vastuu ja korvaus, jos toimittajan laiminlyönti aiheuttaa asiakkaalle vahinkoa tai velvoitteiden rikkomisen. | | |

**Julkinen hankinta.** Erottele tarjouspyynnössä ehdottomat vähimmäisvaatimukset (esimerkiksi ehdot 18, 20 ja 22) ja vertailuperusteet (esimerkiksi selitettävyys, testaustulosten kattavuus, lokien saatavuus).
