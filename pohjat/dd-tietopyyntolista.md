# Tietopyyntölista: tekoäly ja EU:n tekoälyasetus (due diligence)

> Ostajan tietopyyntö kohdeyhtiölle. Myyjä voi käyttää samaa listaa valmistautumiseen. Sovita laajuus kohteen kokoon ja liiketoimintaan.

| # | Pyyntö | Prioriteetti | Toimitettu |
|---|---|---|---|
| **A** | **Yleiskuva** | | |
| A1 | Luettelo tekoälyä käyttävistä tuotteista, toiminnoista ja sisäisistä käyttötapauksista (inventaario) | Korkea | |
| A2 | Kunkin tuotteen tekoälyominaisuuksien tekninen kuvaus ja käytetyt mallit tai palvelut | Korkea | |
| A3 | Tuotteiden käyttötarkoitus ja asiakassegmentit, erityisesti HR, koulutus, rahoitus, vakuutus, terveys, kriittinen infrastruktuuri ja julkinen sektori | Korkea | |
| A4 | Tekoälyyn liittyvä liikevaihto ja sen osuus | Keskitaso | |
| **B** | **Sääntelyn arviointi** | | |
| B1 | Yhtiön omat riskiluokitukset (kielletty, suuririskinen, avoimuus, vähäriskinen) ja roolit (tarjoaja, käyttöönottaja ym.) | Korkea | |
| B2 | 6 art. 3 kohdan poikkeusarviot ja niiden rekisteröinnit | Korkea | |
| B3 | Suunnitelma ja budjetti suuririskisten tuotteiden velvoitteille (laadunhallinta, tekninen dokumentaatio, vaatimustenmukaisuuden arviointi) | Korkea | |
| B4 | Avoimuusvelvoitteiden toteutus (chat-ilmoitukset, synteettisen sisällön merkintä) | Keskitaso | |
| B5 | Yleiskäyttöisten mallien kehitys tai merkittävä muokkaus (hienosäätö) ja koulutuslaskennan määrä | Keskitaso | |
| **C** | **Hallinto** | | |
| C1 | Tekoälyn hallintamalli, käyttöperiaatteet ja vastuut | Keskitaso | |
| C2 | Tekoälylukutaitotoimet ja niiden dokumentointi (4 art.) | Keskitaso | |
| C3 | Hallituksen tai johtoryhmän käsittelyt tekoälyriskeistä | Matala | |
| C4 | Sertifioinnit ja auditoinnit (esim. ISO/IEC 42001, ISO/IEC 27001) | Matala | |
| **D** | **Data** | | |
| D1 | Koulutus-, validointi- ja testidatan lähteet ja oikeudet | Korkea | |
| D2 | Asiakasdatan käyttö mallien koulutukseen ja sopimusperuste | Korkea | |
| D3 | Tietosuojan vaikutustenarvioinnit (DPIA) tekoälykäsittelyistä | Keskitaso | |
| D4 | Vinoumien testaus ja tulokset | Keskitaso | |
| **E** | **Sopimukset** | | |
| E1 | Mallien ja tekoälypalvelujen toimittajasopimukset (vastuut, tiedonanto, muutokset, käsittelysijainti) | Korkea | |
| E2 | Asiakassopimusten tekoälyä koskevat ehdot ja vastuunrajaukset | Korkea | |
| E3 | Asiakkaille annetut käyttöohjeet ja käyttötarkoituksen rajaukset | Keskitaso | |
| **F** | **Vaaratilanteet ja viranomaiset** | | |
| F1 | Tekoälyyn liittyvät vaaratilanteet, asiakasvalitukset ja korjaavat toimet | Korkea | |
| F2 | Viranomaisyhteydenotot, tietopyynnöt ja tarkastukset (Traficom, tietosuojavaltuutettu, muut) | Korkea | |
| F3 | Vireillä olevat tai uhkaavat riidat | Korkea | |
